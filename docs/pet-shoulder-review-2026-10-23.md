# 浮灵肩部渲染验证（2026-10-23）

本轮仅验证现有模型，没有调整正式网格、骨骼、材质或动作参数。结论：可以复现上臂与身体连成一片的观感，肩部外观仍未通过验收；尚不能据此确定修正幅度。

## 方法与证据

- 使用正式 `desktop/src/pet/spirit_view.py` 的 SpiritView 和现有 CharacterSpirit.qml，在隐藏 Qt 窗口读取 framebuffer，不截取用户桌面。
- 保留自然运动和动作过渡；动画时钟按 60 Hz 推进，每秒取 12 个采样点，每个时刻固定后分别渲染正面 0°、斜侧面 45°、侧面 90°。
- 顺序为 idle → dizzy → idle → wave → idle → stretch；共 102 个动画采样点、306 张图。
- 已查看整体三视角联系表及肩部放大联系表，重点对照待机、眩晕、挥手 0.25/0.5/1 秒、伸展 1.5 秒。没有将生成全部截图等同于逐张人工审查。
- framebuffer 为 960×996 像素，对应 640×664 逻辑尺寸；肩部裁切已按设备缩放换算。

## 实际观察

| 场景 | 结果 |
| --- | --- |
| 放下手臂，正面 | 肩根与胸侧连接偏宽，上臂贴近躯干，主要只有前臂显露，能复现用户截图中的问题。 |
| 放下手臂，45°/90° | 上臂仍存在；肩部鼓起，腋下凹口浅，同色材质进一步弱化了上臂轮廓。 |
| 挥手 0.25–0.5 秒 | 抬手后上臂轮廓开始显露，但肩部鼓包与转折仍可见。 |
| 挥手 1 秒、伸展 1.5 秒 | 肩根与腋下存在局部凹凸和挤压感，连续形体仍不够顺滑。 |

所查看画面未发现明显破洞或断裂。渲染只能确认轮廓和表面观感，不能单独证明或排除内部几何自相交；也未隔离测量骨骼权重和肩部修正形态各自的贡献。

## 后续调整的验收边界

优先分别验证：轻微增加放松姿态的上臂外展，以及调整肩根到胸侧的过渡。每次只改一个因素，沿用本轮相机、灯光和采样时刻比较，再判断是否需要修改权重或肩部修正形态。不能仅凭现有截图指定一个幅度并声称已验证有效。

验收要求：放下手臂时能读出上臂与躯干的关系；抬手中间帧无明显局部鼓包或夹褶；正面与侧面都保持自然连接。保留圆润小手，不增加手腕或放大成球状手掌。

本轮前后 CharacterSpirit.qml、DreamSpiritRuntime.qml 与 spirit_Body_softarms_mesh.mesh 的 SHA-256 一致，记录中的 `assetsUnchanged` 为 true。产物仅包括临时渲染脚本、截图、索引及本验收文档，未运行工程测试。
