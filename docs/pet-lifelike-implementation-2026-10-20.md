# 浮灵日常行为第一阶段实施记录

日期：2026-10-20。目标与后续 38 项行为清单见 [日常生活与互动设计](pet-lifelike-behavior.md)。

本文记录最初的 12 组活动。后续已加入“趴在任务栏边看你”，当前共 13 组；新增的程序化双手搭边姿态、缩放和打断验证见 [任务栏互动实施记录](pet-taskbar-interaction-2026-10-20.md)。

## 已落地

复用正式浮灵现有的 16 个基础动画，新增 12 组连续活动：伸展、整理、张望、托腮、招手、散步、巡视、颠球、推球、静坐、打盹和小睡。这些是行为编排，不是新制作的 12 条骨骼动画。

本地调度按精力、好奇和社交需求给活动加权，包含六种心态、活动冷却与最近三组去重。活动有起始、停顿和收尾；日常/活泼模式分别间隔 30–70 / 16–36 秒发起活动，安静/休息模式不主动外出。

散步和巡视会实际移动宠物窗口，限制在最近摆放位置附近并约束在屏幕可用区内；拖动、缩放或明确移动后更新活动中心。小球是角色场景内的三维道具，有弹跳、滚动和目光跟随。

任务状态、指引、倾听、说话和拖动接管时，取消日常活动并收起小球。鼠标靠近、左键按住或聊天/语音/输入面板与菜单打开时，暂停活动进度和自主位移。该逻辑已接入；真人交互与服务完整联调尚未验收。

入口为宠物或托盘菜单的 **陪伴方式 → 一起玩**，可以主动选择 12 组活动；上方显示当前活动或心态。Python 界面更新后需重新启动桌宠，工程根目录运行 `npm run start:pet`。

## 代码分工

| 文件 | 职责 |
| --- | --- |
| `desktop/src/pet/behaviors.py` | 活动数据、步骤时长、心态和冷却 |
| `desktop/src/pet/companion.py` | 本地需求、调度、优先级、移动和目光 |
| `desktop/src/pet/spirit_view.py` | 姿态重播及 Qt 展示参数 |
| `desktop/res/role/浮灵/CharacterSpirit.qml` | 正式角色的朝向、轻微倾斜和三维球 |
| `desktop/src/pet/desktop_pet.py` | 信号装配和本地面板/交互状态 |
| `desktop/src/pet/desktop_actions.py` | 调整摆放后更新活动中心 |
| `desktop/src/pet/desktop_interactions.py` | 拖动和落位接管 |
| `desktop/src/widgets/menus/pet_menus.py` | 活动与心态菜单 |

没有新增模型会话、网络轮询、持久化需求数据库或通用行为树框架。环境几何与后续接触动画独立于活动目录。

散步记录显示，预览中的宠物位置从 `(460, 360)` 移到 `(616, 346)`，经历停看、坐下后，在第 26 秒回到 `(460, 360)`。打盹样本包含休息和醒来后的姿态，玩球样本包含道具出现、弹跳、随行和收起。

预览使用隐藏的自身 Qt 窗口与 `grabFramebuffer()`，不观察桌面或其他应用。它确认了正式资产可以渲染、球可见和编排中的位移；不能替代连续动画、跨屏边界和真人打断的现场验收。

## 尚未完成

- 软件后探头、趴窗口边、坐窗口角、图标绕行：已设计，尚未接入环境几何和遮挡。当前仍为置顶宠物。
- 小球尚非独立物理对象，没有真实碰撞、精确接球、手部接触约束或鼠标抛球。现有玩耍片段与球轨迹是视觉编排，仍需专用接触动画。
- 六种心态目前控制活动选择与节奏，主要表情沿用现有动画；没有新制作完整的情绪表情层或跨重启心态。
- 聊天/语音/指引打断、实际屏幕边缘、不同缩放比例与长期重复率尚需现场验收。

下一阶段继续补探头、窗口趴沿适配、揉眼、接球与收手的动作资产，再完成普通窗口侧边的接近—藏身—探头—回应—退出闭环。任务栏基础搭边已在后续完成，尚不代表窗口或图标互动完成，也不能将第一阶段称为达到最终拟人效果。
