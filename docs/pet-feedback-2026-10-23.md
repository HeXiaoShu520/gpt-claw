# 浮灵动作反馈实施记录

日期：2026-10-23。对象：gpt-claw 专属宠物的正式 Qt / 3D 角色入口。

本轮把移动、拖动和落地接成连续反应，补充气泡、惯性和轻音效。浮灵保持现有 3D 模型与 Codex 单内核架构；这些回应由本地界面完成。

## 当前体验

| 场景 | 已实现的反应 |
| --- | --- |
| 散步 | 随速度摆臂，转向时轻微侧身；身后出现少量青紫气泡，停下后约 0.8 秒淡出；头部、身体、飘带和尾部有阻尼回摆 |
| 被提起 | 拖动达到阈值后切换被提起动作，记录近期移动速度，播放短提示音 |
| 松手 | 默认保持悬浮；开启掉落后保留释放速度，受重力下落，碰到侧边会减速反弹 |
| 落地 | 0.45 秒压缩缓冲，随后 0.8 秒恢复；竖直落地速度超过 850 像素/秒时，中间增加 2.2 秒眩晕 |
| 眩晕 | 身体和头部轻晃、困惑表情、头顶星星，以及“慢一点……月亮都转起来了。”短句；短句至少间隔 30 秒 |
| 任务栏 | 从附近走向底部任务栏，沿边散步、双手搭边看你，再退回原位；任务栏接触阶段按边界裁剪显示和输入区域 |

完整状态清单现为 **21 个**：待机、休息、睡觉、挥手、指引、思考、说话、倾听、等待确认、下落、落地缓冲、眩晕、恢复、被提起、坐下、伸展、张望、玩耍、整理衣帽、散步、双手搭边。这是运行时状态数，包含程序姿态与已有动画叠加，不表示新增了 21 段 Blender 动画。

连续活动现有 **13 种**：伸展、整理、好奇张望、思考、打招呼、任务栏互动、附近散步、巡视、玩球、滚球、坐下陪伴、打盹和长睡。任务、倾听、语音和指引继续使用统一调度；有任务需要注意时，不排队补播落地小剧场。

## 开关与声音

右键宠物，进入 **陪伴方式 → 动作反馈**：

- **气泡与眩晕特效**：控制移动气泡、眩晕星星和对应短句，默认开启。
- **轻音效**：控制移动、提起、落地和眩晕提示音，默认开启。
- **松手后掉落**：默认关闭；开启后才进入下落与落地反应。关闭时若正在下落，会停止下落并恢复悬浮。

设置保存到桌宠现有配置。关闭特效不影响动作，关闭音效不影响视觉反馈。眩晕短句不调用模型，也不写入聊天记录。

四个 WAV 位于 `desktop/res/sounds/spirit/`，由本工程合成，不使用第三方采样。单声道、24 kHz、16 bit PCM；时长为 0.10、0.18、0.22、0.62 秒。按全局音量进一步衰减，限制播放频率，不叠加堆积；安静模式、休息模式、语音会话和隐藏期间不触发动作提示音。

## 来源与实现边界

参考 [Coopanion](https://github.com/Pal-AI-Lab/Coopanion) 对移动、拖放和落地的组合反馈方式。只读审阅的版本为 `04ce022a8c1e96e6053d9cbbe8f6dc555aa93f33`，其许可证为 AGPL-3.0-or-later 并附带第 7 节 Steamworks 条款。本轮没有复制上游源码、模型、动画或音效；使用浮灵现有 Qt / 3D 路径独立实现，WAV 为原创合成音。

## 渲染与验证

使用正式 `SpiritView` 进行隐藏 Qt 帧缓冲渲染，不截取用户桌面。保持自然眨眼，按顺序推进角色时钟并采集 **12 帧**：散步正面、散步侧面、刚停下、停稳、提起、下落、落地压缩、落地释放、眩晕初期、眩晕中期、恢复，以及 280 × 290 逻辑尺寸的眩晕画面。

已逐图检查：移动气泡位于身体后方，停下后淡出；落地压缩与释放可区分；星星和短句避开脸部，小尺寸下仍可辨认。该结果证明这些姿态与叠加层能在正式渲染入口显示，不等同于完整桌面交互验收或全程动画观感验收。

## 尚未覆盖

- 任务栏互动目前只支持底部常驻任务栏，未完成自动隐藏、侧边任务栏与真实多屏拖放验收。
- 落地仍沿用桌宠窗口底边作为接触边界，模型身体与桌面接触点尚未单独校准。
- 窗口后探头、桌面图标识别与图标互动尚未实现。
- 尚未完成真实桌面上拖放、任务栏进出、各开关的完整操作验收，以及四个提示音的真人听感验收。

重启桌宠后加载本轮 Python 和 QML 修改。原启动约定不变：`npm run start` 启动服务和桌宠，`npm run start:pet` 只启动桌宠。
