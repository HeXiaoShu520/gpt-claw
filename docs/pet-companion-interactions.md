# 桌宠触摸、招呼与陪玩

2026-10-21：在正式浮灵角色上接入摸头回应、点击唤醒、点击小球，以及招手后的等待与回应，让用户的动作能改变正在进行的活动。复用现有动画和程序化姿态，基础动作数量仍为 18 个状态，连续活动目录仍为 13 组。

## 怎么使用

| 操作 | 回应 |
| --- | --- |
| 单击头部，或不按鼠标在头部左右来回轻抚 | 歪头、眯眼微笑，放松后看看你 |
| 睡着时单击头部 | 慢慢睁眼、伸懒腰，再张望一下 |
| 菜单 → 陪伴方式 → 一起玩 → 看看你再招手；招呼时把鼠标移近并稍作停留 | 先看你、招手、等待；收到回应后笑眼点头，再放松 |
| 菜单 → 陪伴方式 → 一起玩 → 颠颠小球；球出现后点击球 | 连续点击给球加力，睁眼跟随；落稳后笑眼点头、看看你 |
| 双击宠物 | 使用现有输入入口 |
| 按住并拖动宠物 | 使用现有拖动，不触发摸头 |

单击等待系统双击间隔后响应，避免把打开聊天的双击同时解释为摸头。移动达到现有 6 像素拖动阈值即取消待触摸。轻抚需要连续的左右往返，触发后有 3.5 秒冷却，普通鼠标经过不会每次触发。

鼠标靠近时，原地玩耍和触摸回应继续进行；外出位移仍暂停。打开桌宠自身面板、菜单或按住鼠标时暂停自主活动。聊天任务、倾听、说话和指引保持优先，工作期间不接受新的摸头陪玩活动。

若选择了持续“睡觉”陪伴模式，点击可暂时唤醒，回应结束后恢复该模式。要保持清醒，切换为日常、活泼或安静陪伴。更新后需要重新启动桌宠。

### 招手后等待回应

“看看你再招手”也会按现有活动选择规则自主出现。先看你约 1.5 秒、招手约 2.1 秒，再等待约 4.5 秒。等待期间状态显示“等你回应”。

鼠标新进入宠物附近，或在附近累计移动至少 12 像素，随后停留至少 0.8 秒，视为一次回应。附近范围为宠物窗口向外扩展 36 像素。短暂路过、活动开始前就停在旁边的鼠标不会触发回应；招手结束前收到的回应会保留，等招手结束再接续。

收到回应后显示“看到你啦”，用约 2.4 秒的笑眼和轻微点头回应，再放松约 1.4 秒。笑眼在 0.25 秒内进入、最后 0.5 秒退出，避免表情突然切换。笑眼与自动眨眼共用眼睑闭合幅度，避免两个形变叠加产生双层眼形。没有收到回应则张望、整理、放松，约 6 秒后结束，不反复招手催促。

打开自身面板会暂停活动并清除尚未完成的停留判定；恢复后需要重新靠近或移动。已确认的回应保留。任务、语音或拖动会取消整次招呼，结束后不会补播旧的回应。点击头部仍优先执行摸头。

### 连续点球与收尾

球出现后可以连续点击，每次给当前运动追加力度，不重启动作或重置球的位置。球的高度和横向范围限制在宠物附近，弹跳与滚动逐渐衰减；跟球时保持睁眼和自然眨眼，让目光变化可见。

球真正落稳后才进入收尾：约 2.4 秒笑眼点头，再约 1.4 秒放松看向你，小球在最后 0.5 秒淡出。收尾期间再次点球可以继续这一局，保留球的位置和转角。打开自身面板会暂停球与步骤进度；任务、语音、指引或拖动接管时取消陪玩并收起球，之后不补播。

### 手臂跟随小球

进入玩球姿态后，靠近球的一只手随球的位置抬起、落下，另一只手自然放松。目标位置经过平滑处理，转身和呼吸时仍按场景坐标跟随；切换姿态继续使用原有过渡与肩部修形。

手臂保持原有长度，不增加手腕或拉长袖子。两段骨骼求解以约 50° 为肘部弯折上限，够不到的球只做伸手邀请。这个限制作用于跟球目标姿态，切入时仍从原动作平滑过渡，不能理解为所有过渡帧都小于 50°。当前是手臂跟随展示，尚未用手的接触驱动球运动。

## 实现位置

- `desktop/src/pet/companion_touch.py`：触摸区域选择、单击延迟、轻抚识别；不承担动画调度。
- `desktop/src/pet/attention.py`：识别新的靠近与停留；与动画、Qt 和桌面接口解耦。
- `desktop/src/pet/desktop_interactions.py`、`desktop_pet.py`、`desktop_actions.py`：接入鼠标事件和现有菜单，拖动、双击优先。
- `desktop/src/pet/companion.py`：编排回应、暂停与优先级，协调落稳收尾和视线。
- `desktop/src/pet/ball.py`：不依赖 Qt 的球运动，处理追加力度、弹跳、滚动衰减与落稳。
- `desktop/src/pet/spirit_view.py`：根据头部、球中心和近似椭圆判断点击区域；点击时查询球的当前投影，避免初始静止球沿用相机未就绪时的坐标。
- `desktop/res/role/浮灵/CharacterSpirit.qml`：输出投影、显示与淡出小球，传入亲近程度、招呼回应强度、跟球状态与球的场景坐标。
- `desktop/res/role/浮灵/assets/DreamSpiritRuntime.qml`：在现有角色上叠加歪头、笑眼与点头，协调笑眼与眨眼的闭合幅度；求解跟球手臂姿态，沿用睡醒过渡、伸展动作与肩部修形。

这些交互均在本地界面处理，不创建额外模型会话，不读取其他应用内容。互动状态保留在界面进程，未增加对话副本或持久化需求数据库。

## 本轮验证

### 招呼分支

使用正式 `SpiritView`、角色 QML 与行为控制器，在隐藏的独立 Qt 窗口中推进 **9 种场景、2340 次状态记录**。对 249 个采样时刻分别抓取正面和斜侧面，共 **498 张 Qt 帧缓冲图像**，无 QML 错误。鼠标与面板状态由回放脚本注入，没有观察或操控用户的桌面。

| 场景 | 记录结果 |
| --- | --- |
| 无人回应 | 等待结束后张望、整理、放松，约 14 秒结束 |
| 等待时靠近并停留 | 约 5.13 秒进入“看到你啦”，笑眼点头 |
| 短暂经过 | 未触发回应 |
| 开始前已停在旁边 | 未触发回应 |
| 招手结束前靠近 | 保留回应，招手结束后约 3.63 秒接续 |
| 面板中途打开 | 暂停并清除未完成的停留；恢复并重新移动后才回应 |
| 任务、拖动中断 | 立即接管，没有补播旧招呼 |
| 点击头部 | 摸头接管，没有叠加招呼回应 |

正面与斜侧面复拍确认笑眼不再叠出双层眼形。2340 次状态记录中，`Blink + EyeSmile` 的最大值约为 `1.00000003`（浮点误差）；完整笑眼时眨眼权重为 0，退出招呼后自动眨眼仍正常出现。

### 连续陪玩

使用正式视图、角色 QML 与控制器，在隐藏的独立 Qt 窗口中回放单次点球、连续点球、左侧小球、面板暂停、任务接管、拖动接管、收尾再次点球和滚动中点球，共 **8 个场景、2448 次状态记录、408 张正面与斜侧面图像**。

- 连续点击保留动作进度与球位置，最高弹起约 1.50 个场景单位；落稳后才进入回应。
- 单次点击后约第 3.38 秒进入笑眼回应；连续点击延长玩耍，约第 4.79 秒才收尾。
- 面板打开 2 秒期间球位置和步骤进度保持不变，结束时间相应延后。
- 任务与拖动接管后立即隐藏球，拒绝期间的点球，结束后不补播旧活动。
- 收尾再次点击、推球移动中点击均从原位置接续；球初次出现且未移动时也能命中。

## 当前边界

头部与球采用投影椭圆命中，未逐三角面拾取。球支持本地弹跳和衰减，尚无真实接球、独立桌面窗口或与图标、其他窗口的碰撞。软件后探头、图标绕行和身体贴近仍按 [日常生活设计](pet-lifelike-behavior.md) 推进。
