# 浮灵任务栏互动实施记录

日期：2026-10-20。接续 [日常行为第一阶段](pet-lifelike-implementation-2026-10-20.md)，加入“趴在任务栏边看你”。当前共 13 组连续活动，保留 16 个基础动画，另有 1 个程序化双手搭边姿态。

## 使用与行为

重新启动桌宠：工程根目录运行 `npm run start:pet`。入口为宠物或托盘菜单的 **陪伴方式 → 一起玩 → 趴在任务栏边看你**。

完整过程为：张望 → 靠近任务栏 → 双手搭边 → 看你约 20 秒 → 离开边缘 → 返回出发位置 → 招手。接近和返回时长随距离调整。搭边时眼睛跟随鼠标，不因鼠标靠近而停止观察；自身聊天、语音、输入面板和菜单仍会暂停活动。

日常或活泼模式下，仅当宠物靠近底边（距接近位置小于 240 逻辑像素）时参与自动选择，冷却 600 秒；手动选择不受距离限制。模型任务进行中不接受新活动。

当前仅支持有足够空间的底部常驻任务栏。侧边任务栏、自动隐藏而未留出底部区域的任务栏不参与此活动，对应菜单不可选。窗口藏身、桌面图标互动尚未实现。

## 接触与恢复

- 通过 Qt 的当前屏幕完整区域和可用区域确定底边，不读取其他应用窗口、文字、截图或图标。
- 基础待机上叠加双臂的两段求解：上臂打开、肘部弯曲、前臂向前，保持小手圆润，不新增手腕或放大球形手。
- 支撑点按当前视口实时投影，避免沿用初始尺寸导致缩小时悬空。双手位于支撑平面稍上方，保留可见手部。
- 任务栏以下的宠物画面和窗口输入区域同步裁剪，退出时清除裁剪。实际 Windows 任务栏点击穿透仍需现场验证。
- 聊天任务、拖动、明确移动、缩放接管时取消活动，先恢复完整可见位置；屏幕可用区域、完整区域或宠物尺寸变化也会取消，不继续使用旧接触点。
- 正常结束返回出发位置。被打断时优先恢复到可用区域，不把藏在任务栏下的位置记作新活动中心。

## 已验证

- `npm run check`、`npm run build` 通过；修改的 Python 模块内存语法编译通过。
- 用正式 Qt 角色分别渲染正面两种目光、斜面和侧面，检查双手、前臂、弯肘与支撑边缘。未读取桌面或其他窗口。
- 在宠物尺寸比例 0.6、1.0、1.6 下，分别运行完整返回、聊天任务打断、重新摆放打断、缩放打断，共 12 个本地 Qt 流程。完整流程均经过 7 个步骤并返回出发坐标；打断后均取消活动、清除裁剪并恢复完整可见位置。
- 三种尺寸下支撑点与底边的纵向偏差分别约为 +0.40、−0.33、+0.07 逻辑像素，均来自窗口坐标取整。

验证使用隐藏的自身 Qt 窗口与 `grabFramebuffer()`，记录真实屏幕区域，拼图中的深色任务栏由预览脚本绘制。流程按固定时间步推进，未新增或运行测试套件。这些结果确认本地流程与投影；不等同于真人连续观感、实际 Windows 任务栏点击、跨屏/DPI 切换或自动隐藏任务栏的现场验收。
