# 桌宠的注意力与视线

2026-10-21：在正式浮灵角色中加入短暂关注和分层转向，让目光有停留、转移和收回的过程。仍由本地界面驱动，不增加模型会话、模型轮询或其他应用的感知。

## 鼠标靠近时的回应

- 鼠标进入宠物附近时，看向鼠标约 2.4 秒；鼠标累计移动至少 12 像素会续上关注时间，缓慢移动也能触发。
- 鼠标停住后自然收回视线，避免一直盯着同一个位置。
- 鼠标离开附近后，最多保留 0.8 秒的最后关注，再回到放松状态。
- 空闲时每隔 5–9 秒小幅看一眼旁边，停留 0.7–1.3 秒。这里只改变视线，不触发外出或读取其他窗口。

鼠标靠近仍按现有规则暂停外出位移。原地玩球、睡觉和任务栏搭边不因靠近而被整体暂停；聊天面板、菜单或按住鼠标时的暂停规则保持不变。

## 谁决定看哪里

姿态继续使用现有调度优先级，视线服从实际占用者，没有另建一套优先级系统。

| 当前状态 | 视线目标 |
| --- | --- |
| 指引实际占用 | 指引目标点；包含指引移动和返回阶段 |
| 休息、睡觉 | 放松并略微低头，睡觉维持闭眼 |
| 思考 | 略微看向上方，避免被附近鼠标拉走 |
| 倾听、说话、等待确认、拖动或自身面板交互 | 鼠标在附近时看向鼠标，否则面向前方 |
| 玩球 | 跟随球的位置 |
| 行走 | 看向行进方向；被鼠标暂停时可转向鼠标 |
| 张望 | 按活动节奏巡视 |
| 其他空闲状态 | 短暂关注附近鼠标，或小幅自主转眼 |

例如，指引时开始倾听，会暂时看向附近鼠标；倾听结束、指引重新获得占用后，再看回指引目标。仅仅存在一个尚未清除的指引点，不会一直抢走视线。

## 眼睛先转，头和身体跟随

本地控制器先用响应速率 12 平滑目标，QML 再分别推进眼睛、头部和身体，响应速率为 18、5 和 2.8。数值越大，跟随越快；它们不是角速度或固定延迟。飘带继续使用弹簧跟随，并改为跟随头部方向。

视线参数先写入 Qt，再推进动画时钟，避免角色用上一帧目标计算动作。角色网格和已有骨骼动画没有在本轮改动，动作数量仍为 **18 个状态、13 组连续活动**。

## 代码职责

- `desktop/src/pet/attention.py`：短暂关注、移动阈值与自主转眼；不依赖 Qt 或桌面接口。
- `desktop/src/pet/companion.py`：复用现有姿态占用，选择指引、鼠标、球或行进方向等目标。
- `desktop/src/pet/spirit_view.py`：将目标与时间按顺序传给 Qt。
- `desktop/res/role/浮灵/assets/DreamSpiritRuntime.qml`：分别平滑眼睛、头部、身体，并推进飘带跟随。

## Qt 回放验收

通过正式 `SpiritView`、`CompanionDirector` 和角色 QML，在不显示到桌面的隔离窗口推进 **1219 帧模型更新、16 段场景**。使用合成鼠标位置和屏幕几何，保存正面及 28° 斜侧面的抽样帧缓冲。QML 加载错误为 **0**。

| 场景 | 核对结果 |
| --- | --- |
| 空闲、鼠标靠近、停住、缓慢移动、离开 | 靠近和累计缓慢移动能触发关注；静止后收回，离开后不持续追踪 |
| 指引 → 倾听 → 等待确认 → 恢复指引 | 高优先级状态接管目标，释放后重新看向指引点 |
| 思考、鼠标停在附近时睡觉、唤醒 | 思考保持目标；睡觉闭眼，未被附近鼠标拉走视线 |
| 玩球 | 视线跟随球的位置变化 |
| 散步、鼠标靠近暂停、离开后继续 | 暂停段位置保持不变，恢复后继续行走并看路 |

鼠标靠近后约 0.25 秒，归一化横向跟随量为眼睛 0.364、头部 0.281、身体 0.138，符合眼睛先转、头和身体稍后跟随的顺序。鼠标静止后，三层逐步回到前方。

已逐组查看正面和斜侧面对照图，核对转眼、转头、睡醒和散步暂停的中间姿态，没有看到明显的新增跳变或穿插。抽样画面与数值回放不能替代真人长期使用，也没有验证实际任务栏、多屏缩放、真实语音或其他窗口的交互。
