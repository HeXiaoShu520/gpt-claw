# gpt-claw 专属宠物

桌宠是 gpt-claw 的专属宠物，也是它的桌面交互入口；不作为独立产品或另一套 Agent。Qt 负责宠物动画、聊天窗口、回复与确认卡、图片展示、语音输入和朗读；Codex 会话、模型配置、工具、记忆与权限由工程根目录的 gpt-claw 服务统一负责。

正式角色固定为 Blender 制作的三维浮灵。旧图片角色、轮换设置和图片动画加载器已移除；动作、陪伴、拖放及目标指引统一走浮灵控制器。接入结构、16 个动作和本地 Qt 验收入口见 [浮灵运行说明](../docs/minipet-spirit-runtime.md)。

当前交互：悬停浮灵显示“聊天 / 语音”，双击打开显示最近 6 条消息的轻聊天，可在同一窗口展开完整记录。单次右键提供聊天、陪伴方式、协助我、设置和退出，动作与辅助工具放在子菜单。单击仍可摸摸，按住拖动可移动宠物；回复卡片双击仍展开快捷输入。关闭聊天保留草稿和进行中的回复；聊天、快捷输入和语音共用当前 Codex 对话。界面与验收范围见 [桌宠交互方案](../docs/minipet-interaction-design.md)。

在工程根目录的 Windows PowerShell 中，可以分别启动服务和界面，也可以组合启动：

| 指令 | 启动内容 |
|---|---|
| `npm run start` | gpt-claw 服务（飞书和桌面通道）+ 桌宠界面 |
| `npm run start:claw` | 单独启动 gpt-claw 服务（Codex 内核、飞书和桌面通道） |
| `npm run start:pet` | 单独启动桌宠界面 |
| `npm run dev` | gpt-claw 服务 + 桌宠；服务源码变化后自动重启服务 |
| `npm run dev:claw` | 单独启动 gpt-claw 服务并监听服务源码 |

`npm start` 与 `npm run start` 等效。分别启动时，在两个终端运行 `npm run start:claw` 和 `npm run start:pet`。桌宠可以先启动，服务就绪后会自动连接。关闭单独启动的桌宠时，服务继续运行。旧指令 `npm run start:desktop` 是 `npm run start:claw` 的别名，`npm run pet` 和 `npm run desktop:ui` 是 `npm run start:pet` 的别名。

组合启动也可双击工程根目录的 `启动 gpt-claw.cmd`。`npm run start` 会复用已经运行的 gpt-claw；若服务由这次命令启动，关闭桌宠时会一起停止。`npm run start` 和 `npm run start:claw` 都按正常流程启动飞书和桌面通道；首次需要扫码时，在终端完成认证。组合启动等待服务就绪后打开桌宠。单独启动界面和组合启动首次都会自动安装 Python 桌面依赖，可能需要下载较大的包。

`npm run dev` 使用相同的组合启动流程，并监听 `src/`、`tools/` 中的 TS/JSON 服务源码。服务重启时桌宠保持打开并自动重连，共享屏幕会关闭，需重新开启。Python 界面、启动器、`.env` 和 Codex 配置的改动需重新运行。复用已有服务时不会接管或重启它，后端日志在原终端；需要开发监听时先停止原服务。终端会明确区分“桌面通道已就绪”和“桌宠已连接”。

桌宠的快捷输入、聊天窗口、引用追问和语音交互使用同一个持久会话。通过界面新建对话或发送 `/new` 都会等待 gpt-claw 确认 Codex 线程已重置，再清除桌宠本地展示记录；失败或断线时保留原记录。点击宠物右键“协助我”子菜单的“看看我在做什么”时，界面会截取最近的前台工作窗口并发送给 gpt-claw；平时只记窗口标题，不截屏或调用模型。

宠物右键菜单的“协助我”提供“共享屏幕”开关，默认关闭且不保存到设置。开启后，后续文字或语音请求可让当前 Codex 会话查看应用窗口、列举窗口、点击/双击/右键、输入文字、滚动、使用快捷键、拖动、切换窗口和打开程序。开关本身不触发模型消息；截图由本地界面按工具请求提供，不持续录屏，闲聊无需截图。电脑观察支持截图、控件树及二者结合；控件信息由独立的 Windows-MCP 采集环境提供，自绘区域仍依靠截图。首次运行 `npm run computer:setup` 安装控件采集依赖；未安装或控件读取失败时仍可使用纯截图。元素定位、条件等待、用户接管和当前验收范围见 [混合桌面实施方案](../docs/computer-integration.md)。

开启共享同时授权上述电脑操作，不再逐次弹确认卡；权限仅绑定开启共享的桌宠连接及其前台请求，飞书、后台任务和定时任务不能使用。关闭共享、断线、成功新建对话或退出时撤销授权；已发生的点击/输入不能撤回。按 **Ctrl+Alt+Esc** 可关闭共享并取消当前请求。每次操作依据最近截图及目标窗口校验，操作后返回新截图；截图为当前应用窗口及其菜单/弹窗，按比例缩至最多 1600×900，操作坐标为相对截图的 0–1000。切换目标需重新观察。管理员窗口、UAC 安全桌面和受保护画面可能无法操作或截图。

生成图片会立即显示在桌宠回复卡片和聊天窗口，文件保存在工程 `workspace/{sessionId}/artifacts/`；桌面聊天记录引用该文件。其他生成文件在两处都有“打开文件”入口。图片或文件在回答过程中到达时，会插入当前聊天而不重建正在输出的气泡。拖入的文件会复制到当前会话的 `workspace/{sessionId}/inbound/desktop/`，供 Codex 读取；单个文件上限 20 MB，一次消息所有附件合计上限 28 MB。语音识别和朗读沿用火山引擎，唤醒词在本地运行；未配置时文字聊天和图片仍可使用。

开启连续对话后，每轮回复和朗读结束会自动重新接听。接听期间一分钟没有新的语音输入，就结束本次接听，回到等待唤醒；未启用唤醒词时进入待机。新输入会重新计时，回复生成和朗读不计入空闲时间。超时保留连续对话设置，再次唤醒或手动开始即可继续。

桌面连接参数保存在工程 `data/desktop-connection.json`，只监听 `127.0.0.1`，令牌每次服务启动重新生成。`desktop/data/` 保存界面设置与展示历史；真实 Codex 对话和业务数据由工程根目录管理。每条桌面输入都有固定轮次 ID，快捷命令、模型回答和失败结果均回到该轮次。连接中断后桌宠自动重连，同一进程内仍在进行的回复和确认卡会恢复到原卡片；已完成但尚未送达的结果由 gpt-claw 发件队列重试。若断线 20 秒后仍无法关联结果，桌宠会将该轮标为“结果未确认”并解锁输入框；同一桌宠进程稍后收到该轮成功结果时会补写到聊天记录。聊天窗口只把回答正文累积为流式消息，思考进度显示在输入区上方的固定状态条；回复卡片也使用独立状态行。最终消息下方会保留模型、Token 和耗时信息。

悬浮回复卡分为标题、独立状态栏、可滚动正文和页脚。执行时自动展开最近 50 条进度，结束或等待确认时自动收起；手动展开或收起“过程”后尊重本次选择。正文不混入状态小字，翻看旧进度时新进度不抢滚动位置。页脚仅显示本轮 Token 合计和耗时，悬停可查看模型、输入/输出、缓存和累计等原始统计；没有用量时不显示空页脚。底部不放复制或继续聊按钮；框选文字后弹出“复制”，也可用 Ctrl+C。双击卡片空白或标题区域展开输入框，在当前 Codex 对话中发送新消息，不开启连续语音；再次双击或点击输入区的“取消”收起。卡片仍可固定。长确认选项自动换行，操作按钮固定在正文滚动区下方并分行排列，不因卡片宽度丢弃选项。流式输出默认跟随底部，向上滚动查看后暂停跟随。

普通回复结束后不显示“已完成”，也不保留最后一条进行中的状态文字；没有进度记录时隐藏状态栏，有记录时保留“过程”入口。处理、朗读、等待确认和失败时仍显示对应状态。

欢迎、告别及本地短提示只展示标题和正文，不显示“已完成”、复制、继续聊、固定或收起按钮，也不通过双击打开对话输入框。

正式回复不自动倒计时消失。标题栏的收起按钮保留状态及展开入口，任务继续执行，追问草稿也会保留；“停止”单独放在状态栏，点击后显示“正在停止…”，等服务返回实际结果。结束后可用关闭按钮移除卡片。欢迎语和其他显式指定时长的短提示仍会自动消失，鼠标悬停、选择文字、展开过程或追问时暂停。新卡片按实际高度排列，任务进行中、阅读中和固定的卡片不会被新消息自动挤掉；重要回复可固定保存。

桌面协议以 `turn_id` 关联一次输入和结果，以 `surface_id` 关联一张悬浮卡；gpt-claw 保存进行中的 surface 快照供重连恢复。Qt 只负责展示与本地历史：生成媒体和快捷交互先写 `ChatStore`，再增量加入聊天窗口；聊天窗口自己发送的消息由它的流式气泡展示，避免重复插入。确认卡保持显示到服务返回结果，关闭卡片时清除本地 surface 映射。

日常交流音色仅保留 vivi 2.0、知性灿灿、柔美女友2.0、撒娇学妹2.0。旧设置中的其他音色在加载时自动切换为 vivi。四种音色的固定试听、启动欢迎、菜单退出告别和唤醒确认音频随工程保存在 `desktop/res/audio/`，共 28 个 WAV 文件。播放时优先使用 `desktop/data/tts_*` 的本地文件，缺失时读取内置资源；自定义试听及聊天朗读仍由火山引擎合成，生成文件保存在 `desktop/data/`。开启语音功能后，固定欢迎和告别音频可以本地播放。欢迎语音在界面启动时播放，告别语音在桌宠菜单选择退出时播放；终端强制结束不会播放告别语音。开始、完成和失败日志输出到启动终端及 `desktop/data/logs/minipet.log`。

目前“看看我在做什么”仍只处理本人点击后的单张窗口截图；持续看游戏画面、基于屏幕活动主动提醒尚未实现。定时任务由 gpt-claw 提供，桌宠还没有专门的提醒管理界面。
